# Solution Design

This folder contains the proposed solution for improving the bakery’s operations based on the identified business challenges 
and process gaps.

The solution design translates business requirements into a structured system approach, outlining how the online bakery application 
will function to support order management, inventory Management, and sales reporting.

It includes system interactions, user roles, and key functionalities required to deliver an efficient and user-friendly experience
for both customers and bakery staff.

The design focuses on improving accuracy, reducing manual effort, and enabling real-time visibility into business operations.
