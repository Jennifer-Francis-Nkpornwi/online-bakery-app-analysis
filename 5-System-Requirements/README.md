# System Requirements

This folder contains the System Requirements Document (SRD) for the online bakery application.

The SRD defines the functional and non-functional requirements of the proposed system, translating business needs into detailed 
system specifications that guide development and implementation.

It outlines how the system should behave, including features such as order processing, payment integration, inventory management,
and reporting capabilities.

The document also captures system performance expectations, usability considerations, and constraints to ensure the solution is 
efficient, reliable, and scalable.

This serves as a bridge between business requirements and technical implementation.
