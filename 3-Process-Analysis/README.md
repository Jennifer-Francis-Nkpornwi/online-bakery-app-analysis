# Process Analysis

This folder contains the analysis of the bakery’s operational processes, including both the current (As-Is) and 
improved (To-Be) workflows.

The As-Is process highlights the inefficiencies in the manual system, such as order errors, lack of inventory 
tracking, and delays in processing.

The To-Be process presents an optimized workflow with automation, improved order handling, integrated payments, 
and real-time inventory updates.

These process models were developed to identify gaps, improve efficiency, and support the design of a scalable digital 
solution for the bakery.

- As-Is Flow Chart of the main operations
